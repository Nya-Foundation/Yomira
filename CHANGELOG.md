# Changelog

Automated releases publish their changes in [GitHub Releases](https://github.com/k3scat/Yomira/releases).
The milestones below summarize local development before public release.

## 0.2.2

- Applied Yomira branding to Windows installers, uninstaller icons and Android
  standard, round and adaptive launchers.
- Generate platform icons from one checked-in vector master before packaging.

## 0.2.1

- Fixed half-star minimum rating searches and multi-tag autocomplete.
- Added desktop back/forward controls, Android back handling, and desktop
  display zoom shortcuts.

## 0.2.0

- Renamed the application to Yomira while preserving stored data identifiers.
- Fixed Android list pagination and reader swipe navigation.
- Added gallery layout selection, right-to-left reading, image resolution,
  configurable preloading, and built-in/custom hosts support.
- Added responsive UI improvements, offline reading and targeted performance
  and maintainability improvements.
